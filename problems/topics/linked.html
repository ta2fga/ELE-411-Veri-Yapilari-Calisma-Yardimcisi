Bağlı yapıda elemanlar düğümlerde (node) tutulur; her düğüm bir sonrakini gösteren pointer içerir (yük treni gibi). headPtr ilk düğümü, son düğüm nullptr’ı gösterir. (Lecture 3–4: Link-Based Implementations)

Node (Lecture 4 + sınav UML’i)

class Node {
public:
    int item;          // veri
    Node* next;        // sonraki düğüm
    Node(int anItem);  // next = nullptr
    // sınav UML'i: getItem(), getNext(), setItem(x), setNext(p)
};

Temel kalıplar

for (Node* cur = headPtr; cur != nullptr; cur = cur->next) { ... }   // gezinme

Node* n = new Node(x); n->next = headPtr; headPtr = n;   // başa ekleme O(1)

prev->next = cur->next; delete cur;                       // cur'u silme (prev gerekli)

LinkedBag (Lecture 4)

  • add: derste liste sıralı tutuluyor: doğru yeri bulup araya ekliyor → O(N).
  • remove: getPointerTo ile bul; baştaysa headPtr = headPtr->next, değilse öncekini bulup bağla; delete → O(N).
  • clear / destructor: tüm düğümleri tek tek delete et (bellek sızıntısı olmasın).

Shallow copy sadece pointer’ı kopyalar (iki liste aynı düğümleri paylaşır); deep copy tüm düğümleri yeniden oluşturur.

Sınav tuzakları

  • cur->next’e erişmeden önce cur != nullptr kontrolü; boş liste (headPtr == nullptr) kenar durumu.
  • Kayıp düğüm (Figure 4-5): bağlantıyı değiştirmeden önce sonraki düğümün adresini saklayın.
  • Lecture 4’teki add kodunda baştaki elemana eşit bir değer eklenince prev nullptr kalır ve program çöker; baş kontrolünü >= yapmak düzeltir.
  • Fonksiyon Node* headPtr’ı değerle alıyorsa baş düğümü değiştiremezsiniz; bubble sort’ta düğümleri değil item’ları takas edin.
