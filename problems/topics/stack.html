Stack (yığın): LIFO (Last-In, First-Out) — son eklenen eleman ilk çıkar. Kafeteryadaki tabak yığını gibi: sadece en üste eklenir, sadece en üstten alınır. (Lecture 5 – Stacks, Bölüm 6)

Sınavdaki UML (birebir)

MetotNe yaparKarmaşıklık
isEmpty(): boolStack boşsa trueO(1)
push(item: int): boolEn üste ekler, başarıyı döndürürO(1)
pop(): boolEn üsttekini siler; değer döndürmez, sadece başarıO(1)
peek(): intEn üstteki elemanın kopyasını döndürür (silmez)O(1)

Array-based ve link-based gerçeklemelerde de push/pop/peek O(1)’dir. Stack içinde arama / sayma / silme ise tüm elemanları gezmek gerektiği için O(N).

Standart kalıp: “sırayı koru, sadece bir yardımcı stack kullan”

Stack temp;
while (!myStack.isEmpty()) {      // 1) boşalt: elemanları temp'e taşı
    int x = myStack.peek();       //    önce peek, sonra pop!
    myStack.pop();
    /* x ile işini yap (say, karşılaştır, atla...) */
    temp.push(x);                 //    temp'te sıra TERS olur
}
while (!temp.isEmpty()) {         // 2) geri doldur: sıra tekrar düzelir
    myStack.push(temp.peek());
    temp.pop();
}

Uygulamalar (Lecture 5)

  • Dengeli parantez: açılışı push et; kapanışta stack boşsa ya da üstteki eşleşmiyorsa → dengesiz. Sonda stack boş olmalı.
  • Postfix hesaplama: sayıyı push et; operatörde iki eleman al: önce alınan sağ operand (op2), sonra alınan sol operand (op1) → op1 op op2 sonucu push.
  • Infix → postfix: operand doğrudan çıktıya; ( push; ) gelince (’a kadar pop; operatörde üstteki operatörün önceliği ≥ ise pop et (soldan birleşme), sonra push. Örnek: a-(b+c*d)/e → abcd*+e/-.
  • Uçuş haritasında yol arama (backtracking).

Sınav tuzakları

  • pop() değer döndürmez: int x = s.pop(); yanlış → int x = s.peek(); s.pop();
  • Boş stack’te peek() çağırmak tanımsız davranış: önce isEmpty() kontrolü.
  • Stack’i fonksiyona referansla (Stack&) geçirin; değerle geçirirseniz yaptığınız değişiklik çağırana ulaşmaz (sd.pdf Soru 7’deki hata).
  • “Sırayı koru” denmişse fonksiyon dönmeden önce elemanları geri doldurmayı unutmayın — return’ü döngünün ortasına koyarsanız geri doldurma atlanır.
  • “Sadece başka bir stack” → dizi, vector, Queue, std::stack kullanmak puan kaybettirir.
  • Postfix’te operand sırası: 10 2 - = 10 − 2 = 8, tersi değil.
